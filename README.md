## 🧭 About This Repository

Welcome to my personal Docker laboratory! This space is dedicated to mastering containerization from the ground up—moving away from traditional setups and diving deep into how modern applications are packaged, networked, and deployed using **Docker** and **Docker Compose**.

---

## 📦 Featured Projects & Architecture

### 1️⃣ `1_data-volumes-args-and-env`
> **Mastering Data Persistence & Configurations**
* **Core Objective:** Ensuring data survives container restarts and managing dynamic configurations cleanly.
* **Key Learnings:**
  * Implementing **Docker Volumes** and **Bind Mounts** for persistent storage.
  * Injecting dynamic runtime configurations using Environment Variables (`ENV`) and Build Arguments (`ARG`).

### 2️⃣ `2_Build-Vercel-With-Docker`
> **Custom Builds & Container Workflows**
* **Core Objective:** Simulating deployment and build pipelines inside isolated containers.
* **Key Learnings:**
  * Writing optimized, production-ready `Dockerfiles`.
  * Streamlining custom build steps and image optimization techniques.

### 3️⃣ `3_MERN-docker-compose`
> **Multi-Container Orchestration**
* **Core Objective:** Spinning up a complete full-stack environment with a single command.
* **Key Learnings:**
  * Orchestrating interconnected services using `docker-compose.yml`.
  * Managing internal container networking, service scaling, and shared volumes seamlessly.
