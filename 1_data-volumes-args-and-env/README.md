# Docker Volumes, Bind Mounts, Arguments & Environment Variables

A Node.js application containerized with Docker to demonstrate:

- Docker Images & Containers
- Named Volumes
- Anonymous Volumes
- Bind Mounts
- Build Arguments (ARG)
- Environment Variables (ENV)
- Dockerfile Configuration
- Port Mapping
- Persistent Data Storage

## Features

- Save and manage feedback entries
- Persistent storage using Docker Volumes
- Live development with Bind Mounts
- Configurable ports using Environment Variables
- Dockerized Node.js application

## Technologies Used

- Node.js
- Docker
- HTML
- CSS
- JavaScript

docker build -t feedback-node .
